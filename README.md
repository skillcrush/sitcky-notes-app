# Super Sticky Notes

A note-taking app built with React and Vite. Work in progress!

## Prerequisites

- [Node.js](https://nodejs.org/) (LTS version recommended)
- npm (comes with Node.js)

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/skillcrush/sitcky-notes-app.git
   cd sitcky-notes-app
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

## Running the app

Start the development server:

```bash
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser (the exact URL is printed in your terminal). The page updates instantly when you edit the code.
